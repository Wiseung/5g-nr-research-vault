# 仿真实验：不同信道模型

> [!abstract] 实验目标
> 在统一的资源、功率、同步、导频、估计器和统计口径下，比较平坦衰落、TDL 与 CDL 信道模型对时频空间 CSI、均衡和算法排序的影响；该实验不把不同模型的默认参数差异误解为算法收益。

## 要回答的问题

- TDL-C、TDL-D 与 CDL-A 等场景下，LS、插值和 LMMSE 的排序是否稳定？
- 频率选择性、时间选择性与空间相关性分别如何改变数据 RE NMSE、EVM 和 BLER？
- CP 不足时的单抽头误差主要来自 ISI、ICI 还是 CSI 估计偏差？
- 端口、天线和层域的 CSI 定义是否与均衡器接口一致？

## 分层模型矩阵

| 级别 | 信道与失真 | 主要验证目标 |
|---|---|---|
| M0 | 单径平坦衰落、理想同步 | LS、均衡与资源索引闭环 |
| M1 | 静态 TDL、CP 足够长 | 频率插值与单抽头均衡 |
| M2 | 时变 TDL、CP 足够长 | 时间插值、预测和 CSI 年龄 |
| M3 | CDL、阵列与预编码 | 空间 CSI、有效秩和 MIMO 均衡 |
| M4 | M1--M3 加 CP 不足 | ISI/ICI 与标量 CSI 失配 |
| M5 | M1--M3 加频偏/相位噪声 | 公共相位、ICI 与 PTRS 边界 |

每次从相邻级别只打开一个因素。若 M0 未通过，不进入后续模型比较。

## 统一配置与公平性

所有模型组需记录并尽量对齐：

- FFT、有效子载波、CP、子载波间隔、符号数和 BWP。
- 调制、编码、块长、MCS、数据 RE 和参考信号资源。
- 总发射能量、数据/导频功率、信道小尺度功率归一化和路径损耗是否包含。
- 载频、速度、最大多普勒、RMS 时延扩展和模型版本。
- 天线阵列、端口数、层数、预编码矩阵和 CSI 域。
- 随机种子、独立信道实现数、错误数和停止条件。

当 TDL 与 CDL 不能同时精确匹配所有统计量时，应说明优先匹配的是 RMS 时延扩展、最大多普勒、平均 SNR、空间相关性还是阵列设置；不应把未匹配的维度归因于估计器。

## 实验 A：时频估计器排序

### 对照组

- 平坦瑞利、TDL-C、TDL-D、CDL-A 或明确记录的替代配置。
- LS + 最近邻、LS + 线性/二维插值、LMMSE/低秩 LMMSE。
- 理想 CSI 均衡作为共同上界。

### 固定量

固定导频图案、总导频能量、数据资源、SNR 扫描、CP 充分条件和理想同步。CDL 组若使用多天线，应另报告 SISO 投影基线或将空间估计单独列为实验 C。

### 记录

- 导频位置、数据位置和边界 RE 的 NMSE。
- NMSE 的均值、90/99 分位和按信道能量分桶结果。
- EVM、BER、TB-BLER、延迟、内存和协方差更新开销。
- 每个模型下算法曲线的置信区间，不根据单个 SNR 点排列算法。

## 实验 B：CP 覆盖与非对角频域信道

在无噪声、理想 CSI 下先扫描：

$$
\Delta_{\mathrm{CP}}=N_{\mathrm{CP}}-(L_h-1).
$$

分别记录：

$$
P_{\mathrm{ICI}}=
\frac{\sum_{k\ne q}|G[k,q]|^2}
{\sum_{k,q}|G[k,q]|^2},
$$

以及跨符号泄漏功率、单抽头均衡 EVM 和完整矩阵或 ICI 块均衡的对照。若 CP 不足时使用单抽头 CSI，必须把“模型失配残差”与“导频估计误差”分开统计。

## 实验 C：MIMO/CDL 的 CSI 域验证

固定 $N_t,N_r,N_s$ 和已知预编码矩阵 $\mathbf{W}$，保存：

$$
\mathbf{H}_{\mathrm{prop}},
\quad
\mathbf{H}_{\mathrm{port}},
\quad
\mathbf{H}_{\mathrm{eff}}
=\mathbf{H}_{\mathrm{port}}\mathbf{W}.
$$

逐项验证：

1. 数组轴顺序为接收天线、发射端口、子载波、符号和信道域。
2. 无噪声端口导频可正确恢复 $\mathbf{H}_{\mathrm{port}}$。
3. 转换后的 $\hat{\mathbf{H}}_{\mathrm{eff}}$ 与真实层域信道比较使用同一维度。
4. 均衡器不会重复乘以 $\mathbf{W}$。
5. 同时报告端口域 NMSE、层域 NMSE、条件数和 BLER。

## 实验 D：模型失配的 LMMSE

对每一个生成模型，比较：

1. 匹配协方差或 oracle 协方差。
2. 仅匹配时延扩展的简化协方差。
3. 错误相关长度、错误噪声方差或错误空间秩。
4. 不使用先验的 LS 基线。

记录 LMMSE 增益是否随失配退化为 LS，是否出现偏差地板，以及低秩近似的延迟与内存收益。oracle 协方差必须在表格中显式标注，不能作为部署性能。

## 最低验收

1. M0 无噪声基线：导频 LS、单抽头均衡和资源索引误差接近数值精度。
2. M1 CP 足够长：理想 CSI 单抽头均衡不应出现结构化 ICI 地板。
3. M4 CP 不足：单抽头 EVM 变差应伴随可测的 ICI 或 ISI，而非仅以 CSI NMSE 解释。
4. M3 无噪声 MIMO：端口域到层域转换必须通过 Frobenius 范数误差和维度检查。
5. 所有算法排序基于相同随机实现、足够样本及置信区间，不能依赖单条视觉平滑曲线。
