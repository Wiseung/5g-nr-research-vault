# 08 仿真实验：LS 与 MMSE

## 实验目的

在相同 OFDM、导频、信道和噪声条件下比较 LS 与 LMMSE 信道估计，分别观察：

1. 导频位置和数据位置的 NMSE。
2. 估计信道用于均衡后的 EVM、BER 和 BLER。
3. 导频密度、SNR、时延扩展和多普勒对算法排序的影响。
4. LMMSE 的性能收益与矩阵计算复杂度之间的关系。

本实验先采用可控的教学模型验证估计原理，再使用标准化 TDL/CDL 场景进行接近 NR 链路的验证。两类结果不应混为一谈。

## 理论问题

导频位置的接收模型为：

$$
Y_p=H_pX_p+N_p
$$

LS 估计：

$$
\hat{H}_{p,\mathrm{LS}}=\frac{Y_p}{X_p}
$$

以 LS 观测为输入的 LMMSE 形式：

$$
\hat{\mathbf{h}}_{\mathrm{LMMSE}}
=R_{hh}(R_{hh}+R_{nn})^{-1}\hat{\mathbf{h}}_{\mathrm{LS}}
$$

这里的 LMMSE 需要使用与生成信道相匹配或接近的二阶统计信息。若协方差、噪声方差或归一化不一致，必须将其作为独立的失配实验因素。

## 实验 A：平坦衰落基线

### 固定参数

| 参数 | 建议值 |
|---|---|
| 系统 | SISO OFDM |
| FFT 点数 | 128 |
| 有效子载波 | 72 |
| 循环前缀 | 32 |
| 调制 | QPSK |
| 导频间隔 | 每 4 个子载波、每 2 个 OFDM 符号 |
| 信道 | 单径平坦瑞利衰落 |
| SNR | -5 至 25 dB，步长 2.5 dB |
| 帧数 | 以每个 SNR 至少 1000 个独立帧为起点 |
| 随机种子 | `20260821` |

### 对照组

- 理想 CSI + ZF 均衡：验证均衡和调制链路上限。
- LS 导频估计 + 最近邻或线性插值。
- LMMSE 导频估计 + 已知平坦衰落协方差。
- 无信道估计或错误 CSI：作为故障对照，不作为算法结果。

### 预期现象

- 平坦信道中频率插值误差较小，主要差异来自噪声抑制。
- 中低 SNR 下 LMMSE 通常具有更低 NMSE。
- 高 SNR 下 LS 与 LMMSE 的差距缩小。
- 估计误差会使实际 BER 曲线相对理想 CSI 曲线出现性能损失。

## 实验 B：频率选择性 TDL 信道

### 变量

- RMS 时延扩展：短、中、长三档。
- 导频频率间隔：4、8、16 个子载波。
- 插值方式：最近邻、线性、二维线性、Wiener/LMMSE。
- SNR：0、5、10、15、20 dB。

### 重点观察

1. 只在导频位置统计 NMSE 可能高估整体质量，必须同时统计数据位置 NMSE。
2. 导频频率间隔增大后，插值误差可能成为主导项。
3. 真实相关带宽比假设相关带宽更窄时，平滑估计会失配。
4. 频率选择性越强，简单最近邻插值越容易产生局部峰谷遗漏。

## 实验 C：时变信道与多普勒

### 变量

- 归一化最大多普勒：低、中、高三档。
- DM-RS 时间间隔：2、4、7 个 OFDM 符号。
- 是否使用时间方向跟踪滤波。

### 重点观察

- 时间方向导频过稀时，导频位置可能表现良好，但数据符号位置出现明显过期 CSI。
- 增大 LMMSE 的时间相关性并不能自动解决统计模型过期问题。
- 需要区分插值误差、外推误差和真实信道在观测间隔内的变化。

## 指标定义

### 导频位置 NMSE

$$
\mathrm{NMSE}_{\mathrm{pilot}}
=\frac{\sum_{p\in\mathcal{P}}|\hat{H}_p-H_p|^2}
{\sum_{p\in\mathcal{P}}|H_p|^2}
$$

### 数据位置 NMSE

$$
\mathrm{NMSE}_{\mathrm{data}}
=\frac{\sum_{q\in\mathcal{D}}|\hat{H}_q-H_q|^2}
{\sum_{q\in\mathcal{D}}|H_q|^2}
$$

## 结果解释规则

1. 先检查理想 CSI 基线是否符合预期，再评价估计器。
2. LS 与 LMMSE 必须使用相同的信道、噪声、导频和随机实现。
3. 不能只根据单个 SNR 点判定算法优劣。
4. 若 LMMSE 反而更差，优先检查协方差、噪声方差、矩阵维度和功率归一化。
5. 报告均值时同时给出置信区间或独立帧数，避免少量帧造成误判。
