# 仿真实验：导频密度与估计误差

> [!abstract] 实验目标
> 在明确的资源和功率约束下，量化时间与频率方向导频采样对导频位置 NMSE、数据位置 NMSE、EVM、BLER 和净吞吐量的影响，并区分 DM-RS、PTRS、时变和频率选择性造成的收益差异。

## 要回答的问题

- 固定导频资源数时，时间密集和频率密集配置分别适合哪些时频信道？
- 固定总发射能量时，提高导频密度与提高单个导频功率的收益如何比较？
- 相同平均 NMSE 的规则和非规则导频布局，是否产生不同的边界误差或 BLER 尾部？
- 多普勒、频偏和相位噪声下，DM-RS 与 PTRS 的资源应如何分配？

## 基线链路

```text
随机比特
  -> 调制与资源网格映射
  -> DM-RS/PTRS 映射
  -> OFDM 与 TDL/CDL 信道
  -> 同步、FFT、导频提取
  -> LS 或 LMMSE + 时频重构
  -> 均衡、软解调、译码
  -> NMSE/EVM/BER/BLER/goodput
```

基线采用 SISO OFDM；扩展到多端口时，端口训练维度、正交方式和导频开销必须单独记录。每个 SNR 点使用相同的信道与噪声实现比较所有导频方案。

## 固定参数与日志

| 项目 | 基线要求 |
|---|---|
| FFT 与有效子载波 | 记录 $N_{\mathrm{FFT}}$、$N_{\mathrm{use}}$、子载波间隔和 BWP |
| OFDM 时间参数 | 记录 CP、有效符号时长、总符号时长和时隙符号数 |
| 调制与编码 | 记录星座、码率、块长、译码器和 LLR 口径 |
| 信道 | 记录 TDL/CDL 类型、RMS 时延扩展、速度、载频和随机种子 |
| 失真开关 | 分别记录多普勒、频偏、相位噪声、CP 不足与干扰 |
| 导频 | 记录 DM-RS/PTRS 资源集合、端口、序列、功率与配置版本 |
| 估计器 | 记录 LS/LMMSE、协方差来源、插值器、边界策略和 CSI 年龄 |

### 功率约束

每组比较必须选择并记录一种口径：

$$
P_{\mathrm{total}}=N_dP_d+N_{\mathrm{RS}}P_{\mathrm{RS}}.
$$

固定总能量时，增加 $N_{\mathrm{RS}}$ 需要相应调整数据资源或单 RE 功率；不能既增加导频密度又保持数据功率和总能量不变后，将结果解释为纯布局收益。

## 实验 A：固定导频 RE 的时频分配

### 控制变量

- 固定导频 RE 总数 $N_{\mathrm{RS}}$、总发射能量、数据 RE 数与调制编码配置。
- 固定信道总功率和 SNR 定义。
- 只改变时间/频率导频间隔及其布局。

### 扫描矩阵

| 维度 | 建议档位 |
|---|---|
| RMS 时延扩展 | 短、中、长 |
| 归一化最大多普勒 $\nu_D$ | 低、中、高 |
| 时间导频间隔 | 2、4、7 个 OFDM 符号或等资源替代方案 |
| 频率导频间隔 | 4、8、16 个子载波或等资源替代方案 |
| 重构方法 | 最近邻、线性、二维线性、局部 Wiener/LMMSE |

### 指标与判定

- 分别计算 $\mathrm{NMSE}_{\mathrm{pilot}}$、$\mathrm{NMSE}_{\mathrm{data}}$ 和边界 RE NMSE。
- 报告 EVM、BER、TB-BLER、有效吞吐量和净吞吐量。
- 若两种方案导频位置 NMSE 相近、数据位置 NMSE 明显不同，判定差异来自采样/重构而非导频观测噪声。
- 若数据位置 NMSE 较低但净吞吐量较差，判定需要在目标 BLER 下做资源收益比较，不能只宣称精度更高。

## 实验 B：密度与功率的配对比较

### 对照组

1. 固定 $P_{\mathrm{total}}$，增加导频密度并降低数据 RE 或数据能量。
2. 固定 $N_{\mathrm{RS}}$，提高 $P_{\mathrm{RS}}$ 并相应降低 $P_d$。
3. 固定数据吞吐量，增加额外资源以提高导频密度。
4. 固定所有资源但额外提高总功率，作为不能与前三组混淆的能量上界。

### 判定规则

- 将 NMSE 收益、EVM 收益、BLER 收益和净吞吐量增量放在同一表中。
- 必须报告 $P_d$、$P_{\mathrm{RS}}$ 和总能量；缺失任一量的曲线不用于得出密度与功率的因果比较。
- 若高 SNR 出现 NMSE 地板，先按导频密度、插值误差、同步误差和导频污染分组检查，而不继续提升导频功率。

## 实验 C：规则与非规则布局

比较规则梳状、规则块状和满足相同导频 RE 数的非规则图案。除总体指标外，还应输出：

- 每个数据 RE 到最近导频的时间/频率距离分布。
- 内部插值与边界外推资源的掩码及对应误差分布。
- 时频误差相关性与 NMSE 的 50/90/99 分位。
- 每个时隙或传输块的 BLER，而不是只汇总平均 BER。

若非规则布局只在某个边界或某种信道模型下获益，结论应带上该布局、边界策略和时频统计条件。

## 实验 D：DM-RS 与 PTRS 的职责分离

分别运行以下失真开关：

| 组别 | 多普勒 | 频偏 | 相位噪声 | 目的 |
|---|---|---|---|---|
| D0 | 关 | 关 | 关 | 基线 |
| D1 | 开 | 关 | 关 | 时间 CSI 采样需求 |
| D2 | 关 | 开 | 关 | 公共相位与 ICI |
| D3 | 关 | 关 | 开 | 相位跟踪需求 |
| D4 | 开 | 开 | 开 | 组合失真边界 |

对每组分别扫描 DM-RS 时间密度与 PTRS 密度，记录公共相位误差、ICI 能量、数据 NMSE、EVM 和 BLER。不得仅通过 PTRS 带来的收益推断所有时变问题都由相位噪声造成。

## 最低验收与停止条件

1. 无噪声、静态、单位信道下，导频序列、资源索引和 LS 导频位置误差应接近数值精度。
2. 固定导频覆盖全部数据 RE 时，插值误差应消失，数据位置误差退化为直接观测误差。
3. 每个 SNR 点记录独立帧数、错误块数、随机种子和停止条件；零错误只能报告上界或置信区间。
4. 所有布局比较必须使用相同的信道实现和数据比特，避免蒙特卡洛差异伪造布局收益。
