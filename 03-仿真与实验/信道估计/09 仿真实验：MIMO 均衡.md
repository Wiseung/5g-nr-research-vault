# 09 仿真实验：MIMO 均衡

## 实验目的

在空间复用 MIMO-OFDM 链路中比较 ZF 与 MMSE 线性均衡，研究信道估计误差、空间相关性、天线配置和信道矩阵条件数对 BER、BLER 和吞吐量的影响。

## 系统模型

每个子载波上：

$$
\mathbf{y}[k]=\mathbf{H}[k]\mathbf{x}[k]+\mathbf{n}[k]
$$

ZF：

$$
\hat{\mathbf{x}}_{\mathrm{ZF}}
=(\mathbf{H}^H\mathbf{H})^{-1}\mathbf{H}^H\mathbf{y}
$$

MMSE：

$$
\hat{\mathbf{x}}_{\mathrm{MMSE}}
=\left(\mathbf{H}^H\mathbf{H}+\alpha\mathbf{I}\right)^{-1}\mathbf{H}^H\mathbf{y}
$$

其中：

$$
\alpha=\frac{\sigma_n^2}{\sigma_x^2}
$$

实现时求解线性方程，不显式计算 $(\mathbf{H}^H\mathbf{H})^{-1}$。

## 实验 A：独立同分布信道

### 固定参数

| 参数 | 建议值 |
|---|---|
| 系统 | 2×2 MIMO-OFDM |
| FFT 点数 | 128 |
| 有效子载波 | 72 |
| 循环前缀 | 32 |
| 空间层数 | 2 |
| 调制 | QPSK，扩展实验使用 16-QAM |
| 信道 | 独立瑞利频率选择性信道 |
| SNR | 0 至 25 dB，步长 2.5 dB |
| CSI 条件 | 理想 CSI、LS 估计 CSI |
| 随机种子 | `20260821` |

### 对照组

- 理想 CSI + ZF。
- 理想 CSI + MMSE。
- LS 估计 CSI + ZF。
- LS 估计 CSI + MMSE。
- 单独记录条件数过大的子载波。

### 预期现象

- 理想 CSI 下，SNR 较高时 ZF 与 MMSE 的性能差距缩小。
- 低 SNR 或信道矩阵接近病态时，MMSE 通常比 ZF 更稳健。
- 估计 CSI 会使两种均衡器都出现性能损失；ZF 对深衰落和估计误差通常更敏感。

## 实验 B：空间相关性

采用发射端或接收端相关矩阵控制空间相关性，例如：

$$
\mathbf{H}=R_r^{1/2}\mathbf{H}_wR_t^{1/2}
$$

变量：

- 相关系数：$0$、$0.3$、$0.7$、$0.9$。
- 天线配置：2×2、4×4、8×8。
- 空间层数：不超过有效空间秩。

记录：

- 每个子载波的最小奇异值。
- 条件数 $\kappa(\mathbf{H})$。
- ZF/MMSE 的后均衡 SINR。
- BER、BLER 与吞吐量。

空间相关性升高时，矩阵条件数可能变大，ZF 的逆运算对噪声和 CSI 误差更敏感。若空间层数超过有效秩，均衡器无法稳定分离所有层。

## 实验 C：条件数分桶

将子载波按条件数分成若干区间，例如：

| 分桶 | 条件数范围 |
|---|---|
| 良好 | $\kappa < 5$ |
| 中等 | $5\le\kappa<20$ |
| 较差 | $20\le\kappa<100$ |
| 病态 | $\kappa\ge 100$ |

分别统计每个分桶的：

- ZF 和 MMSE 的均衡误差。
- 后均衡噪声功率。
- 符号错误率和比特错误率。

该分析比只报告全局 BER 更能说明 ZF 性能下降的原因。

## 实验 D：信道估计误差

设置：

$$
\hat{\mathbf{H}}=\mathbf{H}+\tilde{\mathbf{H}}
$$

逐步改变估计误差方差或使用真实导频仿真得到的 LS/LMMSE 估计。至少比较：

1. 理想 CSI。
2. 低 NMSE 估计 CSI。
3. 中等 NMSE 估计 CSI。
4. 高 NMSE 或过期 CSI。

注意：保持真实接收信号使用的 $\mathbf{H}$ 不变，只替换均衡器使用的 $\hat{\mathbf{H}}$，否则无法区分信道变化和估计误差。

## 后均衡噪声与 SINR

对 ZF 线性均衡器，噪声协方差会被矩阵变换放大：

$$
R_{n,\mathrm{ZF}}
=\sigma_n^2(\mathbf{H}^H\mathbf{H})^{-1}
$$

MMSE 通过正则项在干扰消除和噪声增强之间折中。实际系统中还应加入估计误差导致的等效干扰，而不应只用热噪声估算 LLR 方差。

## 验收标准

- 通过与直接求逆的离线小矩阵结果对比，确认线性求解器实现正确。
- 在理想 CSI、低相关、较高 SNR 条件下，ZF 和 MMSE 结果应接近。
- 在低 SNR、深衰落或高相关条件下，应能观察到 MMSE 的稳定性优势或解释为何未出现。
- 所有曲线报告独立帧数和错误计数，避免只展示平滑后的视觉趋势。
