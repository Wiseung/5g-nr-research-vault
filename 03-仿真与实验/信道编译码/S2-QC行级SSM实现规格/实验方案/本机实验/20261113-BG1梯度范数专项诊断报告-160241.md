# 2026-11-13 BG1 梯度范数专项诊断

RUN_ID：`20261113-160241-bg1-gradient`。RTX 4090 GPU 0，FP32 原训练复跑；TF32/AMP 关闭。commit `606439166812f97fb42e30ae3dcfec58ec2b35f9`。本轮完成两配置各100步原样复跑、固定模型/SNR检查、分参数/分轮/分码字梯度分解、无 SSM 的常阻尼对照及数值导数校验。全部为独立诊断，正式训练未启动。

## 结论与证据边界

**当前观测到的 BG1 大范数主要来自 T20 flooding NMS 消息链对阻尼的反向敏感性，梯度集中在阻尼输出 head；没有证据表明是 SSM 状态失控、漏做 BCE 均值归一化，或一次反传实现错误。** 不能仅凭全局范数大或100%裁剪断言训练发散；本轮也没有证明后续长训练稳定。

高范数既存在于初始模型，也存在于100步后的冻结模型。它受噪声难度、具体码字和分段 min/sign/clip 轨迹影响；较大的 BG1 图度数与更强的实测消息链放大相容，但本轮没有测定谱半径，也没有隔离每一种图结构因素，不能把某个度数直接当作唯一因果解释。

## 为什么状态有界仍会出现大梯度

协议将统计特征 detach。固定这些输入时，SSM 状态的历史 Jacobian 就是对角衰减 a=exp(−Delta·lambda)，逐元素介于0和1；状态幅值有界与实测 detach_state 对照相符。但 R/U 仍沿完整译码迭代链保留梯度。

忽略已显式保留的 filler/clip 投影，并将按行广播的阻尼记为对角阵 D，消息的局部递推导数可写成 `J_t ≈ (I−D_t)·alpha·M_t·(G·S−I)+D_t`，其中 G/S 是图 gather/scatter，M_t 是当前 min-sum 分支导数。该式并没有“小于1”的保证；反传包含多个 J_t 的乘积。按 batch 与 B 取均值只规范化损失尺度，不消除这个乘积。这里没有先clip posterior再形成extrinsic，数学定义保持原样。

初始 head 权重约1e−6，也使传入控制器内部的梯度初期较小；head 本身仍直接承受 `d loss/d eta`。因此“head占比高”不能解读成已经证明选择性记忆有效，亦不能据此认为修改 SSM 状态归一化就会解决主要放大。

## 对后续工作的具体建议

1. **保留当前clip=1和原实现作为基准。** 大梯度已定位，但尚无证据支持直接提高阈值；那会改变所有参数的裁剪比例。不要用“提高阈值后不再触发”当问题解决，也不把detach_messages诊断对照并入训练。
2. **先完成正式pilot和alpha标定。** 目前0–2dB、alpha=0.8是调试设置，包含大量难译码字；正式gamma_ref与同一NMS基线冻结后，重新测梯度分布，避免把调试采样区间当训练结论。
3. **正式runner保留这次观察字段。** 至少记录裁剪前/后范数与系数、head/其余参数梯度份额、按SNR的批次组成、少量固定批次的eta梯度随t曲线、AdamW实际更新和固定验证BCE。仅100%裁剪报警不足以判断异常。
4. **如需优化稳定性，独立比较设置。** 先在相同样本流、固定验证集、原T20下比较协议warmup/cosine与当前constant-debug设置；学习率、clip阈值、head参数化或截断反传的改变都应另建实验、分别记录，保持观测数与验证预算一致。截断消息梯度会改变代理梯度定义，需明确标注并重新过对称性/有限性门。
5. **验证实际优化效果与多种子。** 可先做有界的三种子pilot后试跑，以固定验证BCE、误帧及参数更新稳定性评估；不能仅选择较小梯度的配置。本次未执行这些新调参实验，未启动50k训练。
