# 5G NR Research Vault

这是一个用于整理无线通信、5G NR、信道估计与均衡、定位及相关研究资料的 Obsidian 知识库。

## 开始使用

1. 安装 [Obsidian](https://obsidian.md/)。
2. 将仓库克隆到本地，并在 Obsidian 中以仓库根目录打开 Vault。
3. 从 [导航与入口](./00-导航与入口/欢迎.md) 开始浏览。

## 内容结构

- `00-导航与入口/`：主题索引与学习入口。
- `01-专题知识/`：通信与信号处理专题笔记。
- `02-标准与参考/`：标准、资料和参考内容。
- `03-仿真与实验/`：仿真及实验记录。
- `04-文献阅读/`、`ResearchBoard/`：文献阅读与研究笔记。
- `5G-NR-Positioning/`：5G NR 定位相关的协议、测量与算法笔记。
- `Excalidraw/`：知识图示。

## Obsidian 配置

仓库保留可共享的 Vault 配置；插件安装文件、插件本地数据、工作区状态和本机编辑器/环境配置不纳入版本控制。按需在 Obsidian 中安装社区插件。

NR 解码代码目录不属于本仓库内容，并由 `.gitignore` 明确排除。
