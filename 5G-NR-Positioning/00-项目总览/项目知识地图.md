# 项目知识地图

## 1. 当前项目做什么

对第三方被动监测设备采集的 5G NR TDD 同频上下行 IQ 进行离线/实时解析：从小区和帧时频上下文开始，识别 PRACH 随机接入事件，形成有限的 UE 标识候选，沿 PDCCH/DCI 驱动 PDSCH/PUSCH 资源提取，再对多站单 UE 上行信号生成时间观测并进行 TDOA 定位。

主链：[[5G NR Passive Positioning Pipeline]]。

### 现有代码支路与目标定位主链

当前 `NR_decode_test.m` 已有的代码主题是公共下行初始化与系统信息入口：

```text
PSS/SSS -> PCI -> SSB/PBCH -> MIB -> CORESET-0 CSS
  -> SI-RNTI DCI 1_0 -> SIB1 PDSCH
```

这是学习帧同步、MIB、公共 PDCCH 和 SIB1 的入口，不等于目标 UE 的解码。项目定位主链仍需 PRACH/RA 事件关联、C-RNTI、UE-specific SearchSpace、UL grant/PUSCH 或其他可验证上行观测，再进入多站时间校准和 TDOA。当前脚本没有实现这些用户专属步骤；细节见 [[08-MATLAB代码/NR_decode_test 代码学习与协议映射]]。

## 5. 各阶段需要掌握的 NR 知识

- 空口坐标：numerology、SCS、资源网格、BWP、OFDM、TDD。
- 初始下行入口：PSS/SSS、PCI、SSB/PBCH/BCH、MIB、CORESET-0、SearchSpace0、SI-RNTI 与 SIB1；学习页见 [[01-NR基础/SSB PBCH MIB]]。
- 随机接入：PRACH 序列/循环移位/occasion、RA-RNTI、RAR、Msg3、争用解决、C-RNTI。
- 控制/数据：CORESET、搜索空间、CCE/REG、DCI、RNTI CRC 掩码、PDSCH/PUSCH、DM-RS、38.212 编码链。
- 测量/定位：采样时间、ToA/RToA/TDoA、时钟/采样偏差、滤波群时延、几何和质量控制。

## 6. 哪些知识已经掌握

基于现有 Vault 内容，可复用但仍需项目代码核对的部分：OFDM/资源网格、信道估计与均衡、DM-RS、NR DCI/DL-SCH/UL-SCH 编码链、PRACH 到 C-RNTI 的协议边界、PDCCH/PDSCH 盲搜的实验骨架、单用户时频截取和多站 UL-TDOA 误差清单。它们的状态以原笔记中的 `PERSONAL_NOTE`、`STANDARD + partial` 或 `EXPERIMENT + NEEDS_VERIFICATION` 为准。

## 7. 当前最大缺口

1. 真实第三方设备 MATLAB 工程、依赖和版本。
2. 小区配置快照：Release、SCS/BWP、PRACH、TDD、CORESET/搜索空间。
3. RAR/Msg3/Msg4 可见性及 C-RNTI 关联正例/负例。
4. 多站同一事件的公共时钟、RF/滤波延迟、采样率偏差和几何标定。
5. 本机 MATLAB 5G Toolbox API 签名、输入维度和实际运行结果。

## 第三阶段补充：定位观测量接口

第三阶段的单用户支路不只输出一个 ToA 数值，还要输出可回放的观测束：

| 层次 | 入口 | 产物 |
| --- | --- | --- |
| 分类 | [[05-定位观测量/Observation Taxonomy]] | 信号角色、观测类别和标准/项目边界 |
| 标准对照 | [[05-定位观测量/Standard Positioning Observables]] | PRS/SRS、UL/DL-TDOA、Multi-RTT、AoA 的发射源和测量主体 |
| 时间 | [[05-定位观测量/Timing Observation]] | 参考点、样点、ToA/RToA、峰策略和校准 |
| 数据契约 | [[05-定位观测量/Observation Event Schema]] | event_id、observation_id、跨站关联和状态机 |
| 质量 | [[05-定位观测量/Quality and Uncertainty]] | 偏置/漂移/随机误差、协方差和质量门 |

只有通过质量门的 L3 校准观测才进入 TDOA；L0/L1/L2 仍应作为诊断和回放证据保留。
