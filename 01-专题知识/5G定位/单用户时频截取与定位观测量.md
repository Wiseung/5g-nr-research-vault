# 单用户时频截取与定位观测量

> [!abstract] 一句话结论
> “滤波和截断”应建立在已验证的用户资源掩码、方向、时序和参考信号之上；它可以降低带外和邻用户干扰，但未经测量不能把输出称为“干净单用户数据”，尤其不能忽略滤波器群时延对 TDOA 的系统偏差。

## 1. 两类截取操作

| 操作 | 输入域 | 主要作用 | 主要风险 |
|---|---|---|---|
| 频域资源掩码 | OFDM 资源网格 | 保留目标 PRB/RE、去掉其他频域资源 | BWP/Point A/FFT 轴错位；泄漏和多用户重叠 |
| 时域窗/滤波 | 连续 I/Q 或 OFDM 符号 | 限制观测时段、抑制邻带/邻符号能量 | 群时延、边界振铃、CP 破坏、首径被削弱 |

二者不是同一个步骤。先做同步和坐标标定，再根据 `resource_snapshot` 生成掩码；若直接在原始 I/Q 上按猜测时段截断，可能把相邻符号或其他用户一起保留下来。

## 2. 资源到样点的映射

建议为目标用户 $u$ 保存两张有序索引表：

```text
RE 索引表： (frame, slot, symbol, subcarrier, port/layer)
样点索引表： (capture_sample_start, capture_sample_end, FFT_window, CP, filter_delay)
```

现有 [[3GPP TS 38.211｜Physical channels and modulation]] 将 RE 表示为 $(k,l,p)$，并要求区分局部 BWP 下标和绝对子载波号。对目标资源集合 $\mathcal{R}_u$，至少验证：

$$
\mathcal{R}_{u}\cap\mathcal{R}_{other},
\quad
\mathcal{R}_{u}\cap\mathcal{R}_{DMRS},
\quad
\mathcal{R}_{u}\cap\mathcal{R}_{reserved}
$$

各交集是否符合配置。资源重叠可能是合法的端口/码域复用，也可能是单用户假设失效，不能一律删除。

## 3. 推荐的接收处理顺序

```text
保留原始 I/Q 和绝对样点时间戳
    ↓
粗定时、CFO/采样率偏差估计与校正
    ↓
建立 TDD 方向和 OFDM 符号边界
    ↓
按 BWP/PRB/符号生成目标用户资源掩码
    ↓
提取 PRACH/DM-RS/SRS 等已知序列并做相关或 LS 估计
    ↓
在需要时进行频域均衡、干扰抑制或时域滤波
    ↓
输出单用户观测片段 + 质量标记 + 群时延补偿
```

对定位用途，建议优先保留**未滤波参考支路**和**滤波后数据支路**。参考支路用于 ToA/TDOA，数据支路用于解码或 SINR 评估；只保留滤波结果会让后续无法追查峰值偏差。

## 4. 滤波/截断的时间偏差账本

线性时不变滤波器频响为 $G(f)$ 时，群时延为：

$$
\tau_g(f)=-\frac{1}{2\pi}\frac{d\arg G(f)}{df}.
$$

若各站使用不同滤波器或不同通带，测得的到达时间差包含：

$$
\widehat{\Delta\tau}_{ij}
=\Delta\tau_{ij}^{prop}
+(\tau_{g,i}-\tau_{g,j})
+(d_i-d_j)
+e_{ij},
$$

其中 $d_i$ 是射频/采样链硬件延迟。所有站应尽量使用相同滤波器，或在校准表中保存频率相关的群时延并在 TDOA 前补偿。截断窗口还要记录起点、终点、窗函数和边界零填充方式。

## 5. 哪些信号适合作为观测量

| 候选信号              | 已知程度          | 适合的观测           | 限制                   |
| ----------------- | ------------- | --------------- | -------------------- |
| PRACH 前导          | 高（配置可重构）      | 粗 ToA、事件触发、功率   | 碰撞、多径、只能代表接入事件       |
| PDCCH DM-RS       | 高（候选配置已知）     | 控制候选 ToA/质量     | 需要 CORESET/搜索空间和候选关联 |
| PDSCH/PUSCH DM-RS | 高（DCI/RRC 已知） | 当前传输 ToA、CSI、质量 | 端口/层/预编码和资源必须匹配      |
| SRS/定位 SRS        | 取决于配置         | 上行跨站 RTOA、空间观测  | 第三方通常不知道专用配置         |
| 未知业务数据            | 低             | 只能在解码/重构后相关     | 加密、高层未知、误关联风险高       |

“已知序列相关峰”与“解码成功”应作为两条独立输出。对定位，未必需要恢复业务内容；对用户身份关联，则需要 C-RNTI/时序/字段证据。

## 6. 单用户质量指标

不要只用肉眼看波形。至少记录：

- 目标资源占用命中率和掩码覆盖率。
- 目标参考信号相关峰信噪比、峰宽、首峰/最大峰选择规则。
- 滤波前后带内功率、邻带泄漏和残余邻用户功率。
- 参考信号估计的 NMSE/EVM 或等效后均衡 SINR。
- `single_user_confidence`、`collision_flag`、`mu_mimo_possible`。
- 每站的样点时间戳、群时延、RF delay 和采样率偏差。

可把单用户观测定义为：

$$
o_{u,i}=\{\widehat{\tau}_{u,i},\widehat{P}_{u,i},\widehat{\nu}_{u,i},\mathrm{mask}_u,\mathrm{quality}_i\}
$$

其中 $i$ 是站点，$\widehat{\nu}$ 可表示频偏或残余频率误差。定位算法只应消费质量门限通过的 $o_{u,i}$。

## 7. 不能静默假设“干净”的情况

1. 同一 PRB 上存在多个 RNTI 或 MU-MIMO 层。
2. DCI 只给出部分调度字段，专用 RRC/DM-RS 配置缺失。
3. FFT 窗口跨越 flexible/guard 符号或超出 CP 保护范围。
4. 滤波器带宽小于目标信号有效带宽，改变相关峰和首径。
5. 各站本振、采样时钟或数字滤波链不一致。
6. 多径最大峰晚于首径，且算法没有记录峰选择策略。

遇到这些情况时，输出应降级为 `partial_observation` 或 `toa_unreliable`，而不是强制生成一个定位坐标。

## 8. MATLAB 示例：资源掩码、参考支路与 ToA

下面假设资源网格按 `[子载波, OFDM 符号, 天线端口]` 排列，DCI grant 已转成 BWP 局部坐标。数据 RE 与 DM-RS 参考支路分开保留；相关 ToA 使用已知参考序列，不用业务数据支路的峰替代参考测量。

```matlab
% grant.startPRB0/startSymbol0 为 BWP/时隙内 0-based 起点
% grant.nPRB/nSymbols 为分配长度；各 logical mask 为 nSC-by-nSym
% peakThreshold 是通过已知正例/负例标定的归一化相关门限
nPRB = size(grid, 1) / 12;
nSC = size(grid, 1);
nSym = size(grid, 2);
assert(nPRB == floor(nPRB), "资源网格子载波数应为 12 的整数倍");
assert(isequal(size(dmrsMask), [nSC, nSym]));
assert(isequal(size(ptrsMask), [nSC, nSym]));
assert(isequal(size(reservedMask), [nSC, nSym]));

sc = (12 * grant.startPRB0 + 1): ...
    (12 * (grant.startPRB0 + grant.nPRB));
sym = (grant.startSymbol0 + 1): ...
    (grant.startSymbol0 + grant.nSymbols);
assert(~isempty(sc) && ~isempty(sym) && ...
    sc(1) >= 1 && sc(end) <= nSC && ...
    sym(1) >= 1 && sym(end) <= nSym, "grant 超出网格边界");

allocatedMask = false(nSC, nSym);
allocatedMask(sc, sym) = true;
dataMask = allocatedMask & ~dmrsMask & ~ptrsMask & ~reservedMask;
referenceMask = allocatedMask & dmrsMask;
gridData = bsxfun(@times, grid, dataMask);
gridReference = bsxfun(@times, grid, referenceMask);

% 未滤波支路默认用于 ToA；滤波支路用于数据/干扰分析。
% 只有已校准对称线性相位 FIR 才启用滤波 ToA 及群时延扣除。
rxUnfiltered = rx(:);
rxFiltered = filter(b, 1, rxUnfiltered);
groupDelaySamples = (numel(b) - 1) / 2;
useFilteredForToA = false;
if useFilteredForToA
    rxForToA = rxFiltered;
    toaFilterDelaySamples = groupDelaySamples;
    toaBranch = "filtered";
else
    rxForToA = rxUnfiltered;
    toaFilterDelaySamples = 0;
    toaBranch = "unfiltered";
end

ref = knownReference(:);
assert(numel(rxForToA) >= numel(ref) && ~isempty(ref), ...
    "接收窗口必须覆盖非空参考序列");
assert(sampleRateHz > 0 && peakThreshold > 0 && peakThreshold <= 1, ...
    "归一化相关门限必须在 [0, 1] 内");
corrTrace = conv(rxForToA, conj(flipud(ref)), "valid");
rxWindowEnergy = conv(abs(rxForToA).^2, ones(numel(ref), 1), "valid");
refEnergy = sum(abs(ref).^2);
assert(refEnergy > 0, "参考序列不能为零向量");
metric = abs(corrTrace) ./ (sqrt(refEnergy .* rxWindowEnergy) + eps);
[peak, index] = max(metric);
delta = 0;
if index > 1 && index < numel(corrTrace)
    y1 = abs(corrTrace(index - 1));
    y2 = abs(corrTrace(index));
    y3 = abs(corrTrace(index + 1));
    denominator = y1 - 2 * y2 + y3;
    if abs(denominator) > eps
        delta = max(-0.5, min(0.5, 0.5 * (y1 - y3) / denominator));
    end
end

toaSeconds = (index - 1 + delta - toaFilterDelaySamples) / sampleRateHz;
quality = struct("correlationPeak", peak, ...
    "filterDelaySamples", groupDelaySamples, ...
    "toaValid", peak >= peakThreshold && isfinite(toaSeconds), ...
    "toaBranch", toaBranch, ...
    "referenceBranch", "known-sequence correlation");
```

`b` 必须是项目实际使用并已测群时延的滤波器系数；非线性相位、抽取或多级 DDC 链不能只用 FIR 阶数推算延迟。示例中的 ToA 是相对当前 `rx` 窗口起点的估计，还需叠加采集绝对时间戳、补偿 RF/采样链延迟，并记录首峰/最大峰策略。
